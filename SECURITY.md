# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** flow for this repository and include
the affected version, reproduction steps, impact, and any suggested fix.

Maintainers will acknowledge a report within five business days, coordinate
validation and remediation privately, and publish an advisory when a fix is
available. Please do not disclose the issue before that advisory.

Security fixes target the latest released version. Operators should pin
release tags, keep PostgreSQL backups, terminate public traffic with TLS, and
follow [the self-hosting security guidance](docs/self-hosting.md).
